═══════════════════════════════════════════════════════════════
STEP 1: Enable pgvector Extension (2 minutes)
═══════════════════════════════════════════════════════════════

1. Open browser and go to: https://console.neon.tech

2. Login to your Neon account

3. Select your project (the one with database "neondb")

4. Click "SQL Editor" in the left sidebar

5. Copy and paste this command:

   CREATE EXTENSION IF NOT EXISTS vector;

6. Click "Run" button

7. You should see: "CREATE EXTENSION" (success message)

═══════════════════════════════════════════════════════════════
STEP 2: Run Database Migration (1 minute)
═══════════════════════════════════════════════════════════════

1. Open terminal/command prompt

2. Navigate to backend folder:
   cd "D:\Governor Sindh It Initiative\code\full-stack-gym-website\backend"

3. Run migration command:
   npx prisma db push --force-reset --skip-generate

4. Generate Prisma client:
   npx prisma generate

5. You should see: "✔ Generated Prisma Client"

═══════════════════════════════════════════════════════════════
STEP 3: Restart Backend Server (30 seconds)
═══════════════════════════════════════════════════════════════

1. Stop the current backend server (Ctrl+C)

2. Start it again:
   npm run dev

3. You should see: "Server running on port 5000"

═══════════════════════════════════════════════════════════════
STEP 4: Verify Fix (30 seconds)
═══════════════════════════════════════════════════════════════

1. Open browser: http://localhost:3000

2. Homepage should load without errors

3. Go to admin dashboard: http://localhost:3000/admin/testimonials

4. No more 500 errors! ✅

═══════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

If Step 1 fails (pgvector not available):
- Your Neon plan might not support extensions
- Contact Neon support or use a different database

If Step 2 fails:
- Make sure Step 1 completed successfully
- Check if backend server is stopped
- Check internet connection (needs to connect to Neon)

If Step 3 fails:
- Check if port 5000 is already in use
- Kill all node processes: taskkill /F /IM node.exe
- Try again
